# Automatic-Plant-Watering-System
An Arduino-based automatic irrigation system that monitors soil moisture and controls a water pump to provide water to plants when needed
Automatic Plant Watering System

About the Project

The Automatic Plant Watering System is an Arduino-based project designed to monitor soil moisture and automatically water plants whenever the soil becomes dry.

It uses a soil moisture sensor to detect the moisture level in the soil and a water pump controlled through a relay module to supply water when required.

Components Used

- Arduino Uno
- Soil Moisture Sensor
- Relay Module
- Mini Water Pump
- Connecting Wires
- Power Supply
- Water Container

Working Principle

1. The soil moisture sensor measures the moisture level in the soil.
2. Arduino reads the sensor values.
3. When the soil becomes dry, Arduino activates the relay module.
4. The relay switches on the water pump.
5. Water is supplied to the plant.
6. When sufficient moisture is detected, the pump is switched off.

Objective

To develop an automatic irrigation system that reduces manual watering and helps maintain suitable soil moisture for plants.

Technology Used

- Arduino Programming
- Embedded Systems
- Sensor-based Automation

Project Status

Hardware setup and testing completed. Software implementation and integration are in progress.
